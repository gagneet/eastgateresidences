your building – User Guides

Welcome! This portal contains all the information you need to effectively use the your building platform. Based on your user role, you will have access to different guides on the left.

Recommended: Start with the Handbook for your role to see your most common tasks and where to find them.

What's inside

  • Resident Handbook: A comprehensive guide for all residents.
  • Role Handbooks: Role-specific deep-dives for Owners, Tenants, EC Members (including chairperson appointments), Admin Staff, Strata Managers, Strata Admins, and Super Admins.
  • Unit Plan: Official registered units plan (your unit plan) including floor plans and entitlements.
  • Unit Inclusions: A detailed list of standard inclusions for your building\'s units.
Note: Access to these guides is protected based on your registered role. Newly registered users can access the User Guide while their account is pending approval; all other portal features unlock after approval.
Multi-Building Access: Super Admins and multi-property owners will see a Building Selector on login and in the header. The selected building controls which data you are viewing.
Developer and API docs: Super Admins can use the generated Swagger API documentation, OpenAPI JSON, and Postman collection. The shared Postman environment defaults to the demo building (building_id=demo) so test calls do not target East Gate production data unless deliberately changed.
Menu discovery: The sidebar is driven by the backend navigation configuration. New advanced menu suggestions rotate through unseen items on login/config refresh; clicking a suggestion marks that feature as seen, while dismissing a suggestion applies the configured cooldown.
Simple vs. Advanced menu mode: In Simple mode (the default for every role), your sidebar shows only your role's core destinations plus an "Advanced" section that starts collapsed — click it to reveal the rest of the platform's features without permanently changing your menu. Switching to Advanced or Classic mode from the Customise menu shows everything expanded by default instead. Your last-chosen mode is remembered per building.

Advanced Financial Enhancements — What's New

The platform now includes a comprehensive suite of advanced financial management tools:

  • Debt Recovery Board — 4-tier arrears severity tracking (Monitor → Contacted → DCA Eligible → DCA Referred)
  • Section 83 Notices — Formal ACT demand letter PDFs generated instantly
  • DCA Referral — Automated eligibility checks with agency referral workflow
  • Payment Plans — Structured instalment arrangements for arrears owners
  • Special Levies — One-off charges with automatic UOE-based apportionment
  • Capital Funding & Special Levy Workspace — Planned/Pilot workflow for major repairs: compare funding options, collect owner voting/elections, and generate levy-notice PDF preview batches. See the Capital Funding guide.
  • Bank Reconciliation — Monthly statement verification for both funds
  • Payment Matching — Review bank-feed payments that need manager confirmation before allocation
  • Historical Reconstruction — Rebuild levy/expense history for financial years with incomplete dated payment records, through a reviewed, human-approved batch workflow. Includes an Import & Generate step to upload a CSV/JSON of proposed budget, fund closing balances, and actual expense-category spend from whatever source document you have on hand — it tolerates gaps in any of these figures.
  • Financial Health Score — 0–100 composite rating across 7 financial metrics
  • True Cost of Ownership — Annual per-unit cost breakdown across all charge types
  • Tax Summary PDFs — Annual levy summaries for owner tax returns

See your role handbook for which of these features you can access, and use the Payment Matching Guide for queue review steps or the Historical Reconstruction Guide for the batch approval workflow.

Financial core migration status: As of 24 July 2026, East Gate's identity/ownership domain is PostgreSQL read/write. Settings, occupancy, trust ledger, trust reconciliation, and governance now read from PostgreSQL but still write to MongoDB until write-promotion gates pass. Finance remains in shadow mode, so finance workflows continue to use the existing live MongoDB paths until its shadow diffs and reconciliation gaps are closed. See the Financial System Upgrade Guide.

Identity & Registration Enhancements — What's New (May 2026)

Registration and account management have been upgraded with a more secure, building-scoped identity system:

  • Invitation-link registration — Admins can send personalised invitation emails that pre-fill your registration form. Just click the link, set a password, and your account is ready.
  • Building-scoped accounts — Every account is precisely scoped to its building from the moment it is created. You can only see your building's data; nothing crosses between buildings.
  • Multi-building access — Users who belong to more than one building (e.g. portfolio owners, multi-site strata managers) see a building selector on login. Each building remains fully isolated.
  • Improved session security — Sessions now carry a building context so that role and feature checks are always applied to the correct building, even for Super Admins.

See the Registration Guide and the Staff Invitations Guide for full details.

Access Control Enhancements — What's New (March 2026)

Super Admins now have granular, per-user control over both permission flags and feature page access:

  • 192 Seeded Feature Toggle Registry Entries — product modules, cutover controls, safety gates, and preview features are managed through the feature-toggle registry.
  • Feature Access Controls — grant or deny individual users access to specific features independently of the site toggle and their role. Uses an inline 3-state selector: Site Default / Grant / Deny.
  • Access Control Management — set granular permission flags per user with elevation/restriction badges showing at a glance how a user deviates from their role defaults.
  • 3-Layer Access Model — Site Toggle → User Override → Effective Access. Super Admin always bypasses all restrictions.

See the Super Admin Handbook for full instructions.

Document OCR Workspace — What's New (July 2026)

A new general-purpose OCR workspace reads text and structured fields out of scanned or photographed documents — AGM minutes, rates notices, insurance certificates, contracts, maintenance evidence, bank statements, or any other paperwork — and can publish the extracted text straight into your building's document library. It runs in the background so large files never block your upload, and automatically falls back to a safe provider if your building's configured provider is unavailable. See the Document OCR Workspace Guide.

File Upload Safety — What's New (April 2026)

Every file you upload is now automatically scanned to verify it is a safe, recognised file type. The platform checks the actual file content — not just the file name — so harmful programs renamed to look like documents are detected and blocked.

  • Accepted: PDF, Word, Excel, PowerPoint, images (JPEG, PNG, WebP, HEIC), CSV, plain text
  • Blocked: executable programs, shell scripts, code files, Java packages
  • Size limits: 25 MB for documents, 10 MB for photos, 10 MB for CSV imports

If your upload is rejected with "This file type is not permitted", see the Document Upload Safety Guide for help.
