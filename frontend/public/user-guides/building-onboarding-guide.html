Building Onboarding Guide

How to add a new building to the platform using the 8-step onboarding wizard and the current SM-organisation onboarding flow.

Who can onboard a building?

Only Super Admins, Strata Admins, and Strata Managers can access the building onboarding form. Owners, EC members, and tenants do not have access to this workflow.

Navigate to: Dashboard → Admin → Buildings → Add New Building

What the wizard does

The 8-step wizard collects all the information needed to bring a new strata scheme into the platform. When you click Create Building at the end, the system will:

  • Create the building record in the database
  • Assign or invite the strata manager (if provided)
  • Create the executive committee roster (CHAIRMAN is required)
  • Start a scheme onboarding session for the selected SM organisation tenant
  • Record an audit log entry for compliance
Multi-building platform: Each building is fully isolated by its Unit Plan number. Data from one building never crosses into another.

The 8 steps

1

Building Identity +10 XP Required

Unit Plan Number — enter the full plan number (e.g. your unit plan or your-plan-number). The numeric portion becomes the building's system ID. The UP or SP prefix is stripped automatically.

Building Name — the display name used throughout the platform.

Both fields are required to advance.

2

Location & Physical Details +15 XP Required

Enter the street address, suburb, state, and postcode. The State field determines the applicable jurisdiction for compliance rules (e.g. ACT, NSW, VIC).

Street address is required to advance.

3

Lot & Unit Configuration +20 XP Required

Select at least one Lot Type present in the scheme (apartment, townhouse, villa, commercial, carpark, storage). This drives levy entitlements and compliance obligations.

For ACT schemes, you can specify the Class A / Class B demarcation. Class A covers multi-storey apartments; Class B covers ground-level townhouses.

4

Financial & Legal Configuration +20 XP Required

Total Lots/Units — the total number of lots in the scheme (required for levy calculations).

Financial Year End Month — default is June (month 6). Changes this field if your scheme runs a different FY calendar.

Levy Due Months — the months when levy notices are generated (default: March, June, September, December).

Total lots is required to advance.

5

Assign Strata Manager +20 XP

Optional but recommended. You can either:

  • Search existing users — find a strata manager already registered in the system
  • Invite by email — send an invitation to a new strata manager
  • Skip for now — assign later via the Users or Settings section
6

Executive Committee +25 XP CHAIRMAN required

Add EC members. At least one member with the CHAIRMAN position is mandatory — the form will not advance without it.

For each member, either search for an existing user or enter their name and email to invite them. You can add TREASURER, SECRETARY, and MEMBER positions as needed.

The CHAIRMAN row is highlighted in rose — fill in their full name and email before clicking Continue.
7

Import Existing Data +10 XP

Optional. If you have existing levy records, unit lists, or owner registers from another system, this step lets you flag that data import is needed so the follow-up scheme setup can cover lots, members, and opening data in the organisation detail workflow.

8

Review & Launch

Review a summary of all entered data, including building identity, total lots, strata manager, and EC members. The review panel shows a tick or cross against each required item.

Click Create Building to finalise. You will see a success confirmation and be taken to the SM organisation detail view to continue member, lot, and fund setup.

The XP progress system

Each step awards XP points as you complete it. The total XP shown in the header tracks your progress through the wizard. This is a visual guide only — there is no penalty for incomplete optional steps.

Step XP awarded
Step 1 — Identity 10 XP
Step 2 — Location 15 XP
Step 3 — Lots 20 XP
Step 4 — Financial 20 XP
Step 5 — Manager 20 XP
Step 6 — Committee 25 XP
Step 7 — Import 10 XP
Total possible 120 XP

After the building is created

Once the building is created, continue setup from the SM organisation detail view:

  • Review the scheme record created for the selected tenant
  • Add or confirm scheme members
  • Complete lot and ownership setup
  • Capture opening balances and other follow-up onboarding data

Access the follow-up flow at: Dashboard → Admin → SM Organisations → [Organisation]

Switching buildings: Use the building switcher in the header to move between buildings. Your role and permissions are evaluated per-building.

Troubleshooting

Issue Solution
Form shows "Access restricted" Your account role is not Super Admin or Strata Manager. Contact your platform administrator.
"Building already exists" error The unit plan number you entered is already registered. Check the Buildings list or use a different plan number.
Cannot advance past Step 6 Ensure the CHAIRMAN row has both a full name and an email address (or an existing user selected).
Cannot advance past Step 4 Ensure the Total Lots/Units field contains a positive number.
