📋 Rental Certificate Types

ACT Section 119A Certificate — Rental vs Sale Types (July 2024 Amendment)

Overview

Under the Unit Titles (Management) Act 2011 (ACT) — Section 119A, owners must provide a certificate to incoming tenants before lease signing. This has been mandatory since 9 January 2025.

The July 2024 Housing and Consumer Affairs Legislation Amendment Act introduced a separate rental-type certificate with additional fields specific to tenancy arrangements. The portal now supports both certificate types.

Certificate Types

Type When to Use Fee (2025–26) Extra Fields
Sale Unit being sold (original type) $332.00 Standard fields only
Rental New tenancy beginning (July 2024 amendment) $332.00 Tenancy start date, weekly rent
Update Correcting or refreshing an existing cert within 5 years $165.00 Same as original type
Note: Fees are set by ACT Government determination and subject to annual revision. Current fees are based on the July 2025 determination.

Requesting a Rental-Type Certificate (Owners)

  1. Navigate to Dashboard → Rental Certificates.
  2. Click Request Certificate.
  3. Select Certificate Type: Rental from the dropdown.
  4. Fill in the tenant name, lease start date, tenancy start date, and weekly rent.
  5. Click Submit Request. EC/admin will issue the certificate.

Requesting a Sale-Type Certificate

To request a sale certificate (original type), select Certificate Type: Sale in the form. The tenant-specific fields (tenancy start date, weekly rent) are not required for sale certificates.

Issuing a Certificate (EC / Admin / Strata Manager)

  1. Go to Dashboard → Rental Certificates → Manage.
  2. Find the pending request and click Issue Certificate.
  3. Review the auto-populated financial data (levies, arrears, EC members).
  4. Enter insurance details and any known defects.
  5. Click Issue. The certificate is generated and available for PDF download.

The applicable fee is recorded on the certificate and displayed to both the requesting owner and the issuing admin.

Validity and Supersession

  • Certificates are valid for 5 years from the issue date.
  • Issuing a new certificate for the same unit automatically supersedes the previous one.
  • The PDF header shows the correct certificate type (Sale / Rental / Update).
