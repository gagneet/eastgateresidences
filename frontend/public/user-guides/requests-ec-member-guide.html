Requests & Applications — EC Member Guide

Open Dashboard → Requests to discover enabled workflows, review request queues where your permissions allow it, and use My Requests for tracking.

Verified EC Capabilities

  • Access request discovery for the active building as an EC member role.
  • Review pet, access, alteration, insurance and reimbursement items when workflow permissions permit.
  • Access the work-order workspace when the work_orders feature is enabled.

Restrictions

Chairman, Treasurer and Secretary are EC positions, not platform roles. Use the canonical ec_member role. Emergency issues must be escalated outside routine request handling first.
