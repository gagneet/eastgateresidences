🔑 Keys & Fobs Management

Track building access keys, garage fobs, letterbox keys and common area fobs across all units.

Overview

The Keys & Fobs Register is part of the Asset Register page (Dashboard → Admin → Assets). It provides a complete audit trail for every physical access device issued to residents, including garage fobs, entry keys, letterbox keys, common area fobs, and master keys.

ℹ️ Only EC Members, EC Chairman, Strata Managers, and Admins can issue, update, or delete fob records. Owners can view the fobs assigned to their unit.

Key & Fob Types

Type Description Typical Quantity
Entry Key Physical key for main building entry doors 1–2 per unit
Garage Fob Electronic fob for basement/garage roller door 1–2 per vehicle space
Letterbox Key Key for individual letterbox in mail area 1 per unit
Common Area Fob Fob for pool, gym, function room access 1–2 per unit
Master Key Restricted management use only EC/Admin only
Other Any other access device As required

Status Values

Status Meaning
Active Fob/key is currently issued and in use
Returned Fob/key has been returned (e.g. on sale of unit)
Lost Reported lost or missing — may require reprogramming
Replacement Replacement issued; original assumed lost/damaged

Issuing a Key or Fob

Step 1: Go to Dashboard → Admin → Assets and click the Keys & Fobs tab.
Step 2: Click Issue Key/Fob.
Step 3: Fill in the form:
  • Unit Number — the unit this device is being issued to
  • Type — entry key, garage fob, letterbox key, etc.
  • Serial/Fob Number — the unique identifier printed on the device
  • Issued To — full name of the recipient
  • Issue Date — defaults to today
  • Notes — optional (e.g. "Replacement for lost FOB-042")
Step 4: Click Save. The fob appears in the register with status Active.

Marking a Fob as Returned or Lost

Use the action buttons in the fob register table:

  • Return — marks the fob Returned and records the return date. Use this when a unit is sold or a lease ends.
  • Lost — marks the fob Lost. You should then issue a replacement and arrange reprogramming of the garage system if required.

Searching and Filtering

Use the search bar to find fobs by unit number, serial number, or the name they are issued to. Use the Type and Status dropdown filters to narrow results.

Garage Fob Management

Garage fobs require coordination with the building's access control system (typically Paxton or similar). When a fob is reported lost:

  1. Mark it as Lost in the register.
  2. Contact the building manager to deactivate the lost fob in the access control panel.
  3. Issue a replacement fob (type: Garage Fob) and record the new serial number.
  4. Advise the resident of any replacement fee per the by-laws.
ℹ️ A replacement fee may apply for lost fobs. Check the building's By-Laws and Administrative Fund schedule for the current fee.

Owner View (Read-Only)

Owners can see the fobs and keys assigned to their unit by visiting Dashboard → Admin → Assets → Keys & Fobs. The list is automatically filtered to their unit. If you believe a fob is missing from your record, contact your strata manager.
