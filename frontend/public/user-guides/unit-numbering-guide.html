Configuring Unit Numbering for Your Building

What it does

Every lot in your building is identified by its lot number (1, 2, 3, …). Many buildings display units with a prefix — for example apartments as UA001 and townhouses as TH071. Unit Numbering rules tell the portal which prefix and zero-padding to use for each range of lots, so owner accounts, levies, and payments always line up no matter how a unit was typed in (87, U87, or Unit 87).

Where to find it

  1. Sign in with a manager or committee account.
  2. Go to Dashboard → Settings → General.
  3. Scroll to the Unit Numbering card.

Setting up rules

  1. Click Add Rule for each distinct range of lots in your building.
  2. Enter the Prefix (letters only, up to 5 — e.g. UA, TH, or A), the From lot and To lot range, and the number of Digits (zero-padding). The badge next to each rule previews the result.
  3. Ranges must not overlap. Lots outside every rule display as plain numbers.
  4. Click Save Numbering Rules.

Example: a building with 70 apartments and 17 townhouses uses two rules — UA for lots 1–70 and TH for lots 71–87, both with 3 digits — so lot 87 displays as TH087.

Good to know

  • Changing rules only affects how unit numbers are displayed and matched. Your building's stored records, levies, and payment history are never rewritten.
  • Co-owners of the same unit always see the same finance figures — the portal resolves any unit format they were registered with to the same ledger record.
  • Only accounts with user-management permission can change the rules; owners can view but not edit them.
