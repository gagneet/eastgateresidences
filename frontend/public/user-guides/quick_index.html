Financial Year Data Import

Bulk-load financial year data (owner & unit details, levy summary, budget categories, per-unit levy status) using pre-formatted CSV templates. A 5-step wizard guides you through template download, file upload, validation preview, and confirmed import.

  • Available to: Strata Manager, Strata Admin, Super Admin, and EC chairperson where the building grants the required finance permissions.
  • Navigate to: Dashboard → Finance → Financial Year Import
  • See the Resident Handbook for column reference and error handling details.

Capital Funding & Special Levy Workspace

Planned/Pilot workflow for major repairs and strata-loan scenarios. Strata managers prepare funding options at Finance → Capital Funding, owners vote through the linked AGM/SGM/GM item, and preview-only levy notice PDFs are generated after approval checks.

  • Available to: Strata Manager, Strata Admin, Super Admin, EC review roles and Owners where the building enables the pilot feature.
  • Owner path: Meetings → AGM/SGM/GM voting, then the linked Capital Funding election page when elections are open.
  • Guide: Capital Funding & Special Levy Workspace Guide
