Manager Contract Management Guide

This guide is for Strata Admins. It explains how to create and manage strata manager contracts in StrataOS — so that appointments are properly recorded, contract dates are tracked, and expiry notifications are sent automatically.

What Is a Manager Contract on StrataOS?

A manager contract records the formal appointment of a strata manager to a specific building. It captures the key terms of the appointment:

  • Which manager is appointed and to which building.
  • The start and end date of the appointment.
  • The agreed management fee.
  • The notice period required to terminate the appointment early.

Recording contracts in StrataOS means the system can send you automatic alerts before a contract expires, helping you avoid gaps in management coverage or last-minute renewals.

Important: The contract record in StrataOS is a management record — it is not the legally binding document itself. You should still retain the signed contract document in your records and, where required, file it with the relevant strata authority.

Creating a Contract for an Appointed Manager

  1. Go to Admin → Manager Contracts.
  2. Click New Contract.
  3. Select the strata manager from your company's staff list.
  4. Select the building the contract applies to.
  5. Enter the contract start date and end date.
  6. Enter the agreed management fee (annual amount or percentage of levy, depending on your company's fee structure).
  7. Enter the notice period (in days) required to end the contract early.
  8. Optionally, add a note (for example, "Renewal pending EC vote at October AGM").
  9. Click Save Contract.
Tip: You can attach the signed contract PDF directly to the contract record in StrataOS. Use the Attach Document button after saving. This keeps the contract document and the record in one place.

Setting Contract Dates, Fee, and Notice Period

When completing the contract record, keep these points in mind:

  • Start date — should match the date the manager formally took over responsibility for the building (often the date the owners corporation resolution was passed at a general meeting).
  • End date — for a fixed-term appointment, enter the date the contract expires. For an ongoing (month-to-month) arrangement, leave this field blank and set the notice period instead.
  • Management fee — enter the agreed fee amount. This is for your records and does not automatically generate an invoice — fee invoicing is handled separately.
  • Notice period — the number of days' notice either party must give to end the appointment. Common values are 30, 60, or 90 days.

Viewing Expiring Contracts

The Contract Expiry panel on the Manager Contracts page shows all contracts that are due to expire within the next 90 days, sorted by expiry date. For each contract, you can see:

  • The manager's name and the building.
  • The number of days until expiry.
  • Whether a renewal has been initiated.

StrataOS also sends automatic email reminders to the strata admin at 90 days, 60 days, and 30 days before expiry. These reminders go to the email address on your strata admin account.

What Happens When a Contract Expires

When a contract's end date passes, StrataOS does the following:

  • Marks the contract as Expired in the contracts list.
  • Sends a notification to the strata admin alerting them that the contract has expired.
  • The manager's appointment to the building remains active in the system — the expiry of a contract record does not automatically remove the manager from the building. You must take action to either renew or end the appointment.

Renewing a Contract

  1. Open the expired or expiring contract from the Manager Contracts page.
  2. Click Renew Contract.
  3. Enter the new end date (and updated fee if applicable).
  4. Save. The existing record is closed and a new contract record is created for the renewal period.

Ending an Appointment

  1. Open the contract record.
  2. Click End Appointment.
  3. Select the end reason (contract expiry, EC resolution, mutual agreement).
  4. Confirm. The manager is removed from the building appointment and the building will appear as "unassigned" until a new manager is appointed.
Important: Always appoint a replacement or relief manager to the building before ending an existing appointment. A building without an appointed manager will not have a named contact for owners and EC members.
