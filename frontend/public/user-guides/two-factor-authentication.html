🔐 Two-Factor Authentication (2FA)

Secure your account with a time-based one-time password (TOTP).

What is 2FA?

Two-factor authentication (2FA) adds a second layer of security to your login. After entering your password you must also enter a 6-digit code generated by an authenticator app on your phone.

The code changes every 30 seconds, so even if someone learns your password they cannot log in without your device.

Mandatory for: Super Admin, Chairman, and Strata Manager accounts.

Optional for: All other accounts (owners, tenants, EC members).

Setting Up 2FA

Step 1 — Download an Authenticator App

Download one of these free apps on your phone:

  • Google Authenticator (Android / iOS)
  • Microsoft Authenticator (Android / iOS)
  • Authy (Android / iOS)

Step 2 — Enable 2FA in the Portal

  1. Log in to the your building portal.
  2. Go to My Profile → Security → Two-Factor Authentication.
  3. Click Set Up 2FA. A QR code and a 32-character secret key are shown.
  4. Open your authenticator app and scan the QR code (or enter the secret key manually).
  5. Enter the 6-digit code shown in your authenticator app.
  6. Click Verify & Enable. 2FA is now active.

Step 3 — Save Your Backup Codes

After enabling 2FA, you are shown 8 backup codes. Save these in a safe place. Each code can be used once to log in if you lose access to your phone. These codes are not stored in the system and cannot be recovered later.

Logging In With 2FA

  1. Enter your email and password on the sign-in page as usual.
  2. You are automatically redirected to the Two-Factor Authentication challenge page (/login/totp-challenge).
  3. Open your authenticator app and enter the current 6-digit code.
  4. Click Verify. You are logged in and redirected to your dashboard.

Note: The code is valid for ±30 seconds. If it is rejected, wait for the next code to appear in your app and try again.

If you need to use a backup code instead, click "Use a backup code instead" on the challenge page. Backup codes are 8 characters (e.g. ab12cd34).

Disabling 2FA

  1. Go to My Profile → Security → Two-Factor Authentication.
  2. Click Disable 2FA.
  3. Enter a valid 6-digit code from your authenticator app to confirm.
  4. 2FA is now disabled on your account.

Warning: Super Admin, Chairman, and Strata Manager accounts will be prompted to re-enable 2FA at their next login.

Lost Your Phone?

Use one of your saved backup codes to log in. Each backup code can be used only once.

If you have no backup codes left, contact your strata manager or super admin to reset your 2FA.
