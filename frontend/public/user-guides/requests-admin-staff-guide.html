Requests & Applications — Admin Staff Guide

Admin staff can use Dashboard → Requests to find enabled request workflows, help triage request lists and track items in My Requests.

Verified Admin Staff Capabilities

  • Access catalogue discovery and work-order workspace entries when features are enabled.
  • Review request queues where can_manage_requests applies.
  • Confirm required attachments from the form display; do not request extra private documents through notes unless needed for review.

Restrictions

Finance fulfilment, including reimbursement payment marking, requires finance permission. Emergency threats are not routine catalogue requests and must be escalated immediately.
