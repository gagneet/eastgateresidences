Real Estate Agent — Quick Guide

Your role: You manage specific properties on behalf of owners. You only see properties assigned to you.

Getting Started

  1. Login at your building portal
  2. Go to Dashboard → OwnerHub → Agent Dashboard
  3. Review your assigned properties and any pending actions

Key Daily Tasks

  • ✅ Check Maintenance Requests for new/urgent items
  • ✅ Review Leases Expiring Soon (90-day alert)
  • ✅ Update request statuses after tradesperson visits
  • ✅ Reply to tenant messages

Processing a Maintenance Request

  1. Go to My Tenancy → Maintenance Requests
  2. Open the request → click Update Request
  3. Set status, assign tradesperson, schedule date
  4. Mark Completed when done
Emergency requests must be actioned same day. Contact the owner immediately for approval if cost exceeds your delegated authority.
