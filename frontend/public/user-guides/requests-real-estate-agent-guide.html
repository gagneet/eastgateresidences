Requests & Applications — Real Estate Agent Guide

Use Dashboard → Requests to search/filter building-enabled workflows and start permitted requests for properties you are authorised to manage.

Verified Agent Capabilities

  • Start enabled insurance, pet, access-device and alterations requests when a building relationship allows it.
  • Track submitted requests in My Requests.
  • Attach plans or evidence only in forms that provide attachment controls.

Restrictions

Agents cannot use owner reimbursement or work-order management workflows through the catalogue. Visibility is limited to the active building and authorised relationship.
