Document Converter

The Document Converter turns PDF, Word, Excel, PowerPoint and other files into clean Markdown text — a plain-text format that is easy to copy, edit, search, and paste into announcements, meeting minutes, notices, or any other platform content.

Powered by Microsoft MarkItDown, an open-source library used for document intelligence workflows.

Who Can Use It

Available to: all approved residents, owners, EC members, strata managers, and administrators of any building on the platform.
You must be logged in. Guests (pending approval) cannot access this feature.

Convert a File (Upload)

1
Navigate to Dashboard → Document Converter in the left sidebar.
2
The Upload File tab is selected by default. Drag and drop your file onto the drop zone, or click anywhere in the zone to browse for a file.
3
Once a file is selected, its name and size appear below the drop zone. Click Convert to Markdown.
4
The converted Markdown appears in a scrollable preview panel. Use the buttons to:
  • Copy — copies the full text to your clipboard
  • Download .md — saves a .md file to your device
  • New — clears the result so you can convert another file

Convert from URL

1
Click the From URL tab.
2
Paste a publicly accessible URL into the field. This can be a web page, a PDF hosted online, or any other supported document type.
3
Click Convert (or press Enter). The result appears below.
Note: The URL must be publicly reachable — it cannot be a private intranet address, a file behind a login, or a file:// path.

Using the Output

The Markdown output is plain text with lightweight formatting markers:

  • # / ## — headings from the original document
  • **bold** — bold text
  • | col | col | — tables (from Excel sheets or Word tables)
  • - / * — list items

You can paste this output directly into:

  • Announcement body fields
  • Meeting agenda / minutes text boxes
  • Any other rich-text area in the platform that renders Markdown
  • External tools (Confluence, Notion, GitHub, email)

Supported File Formats

PDF DOCX DOC XLSX XLS PPTX HTML CSV TXT MD

Files in other formats (e.g., .zip, .exe, images) are not accepted.

Limits & Notes

Item Limit
Maximum file size 20 MB
File formats accepted PDF, DOCX, DOC, XLSX, XLS, PPTX, HTML, CSV, TXT, MD
URL schemes accepted http:// and https:// only
Converted files stored No — conversion is ephemeral; nothing is saved to the database
Privacy: Uploaded files are processed in memory on the server and immediately deleted. No copy of your file or its content is stored by the platform.

Frequently Asked Questions

The formatting looks messy — is that normal?

Complex layouts (multi-column PDFs, heavily formatted Word docs) may not convert perfectly. Markdown is a linear format, so columns and decorative elements are flattened. You can edit the output after copying it.

Can I convert a scanned PDF?

Scanned PDFs contain images of text, not real text. MarkItDown does not perform OCR (optical character recognition), so a scanned PDF may produce little or no text output. Use a PDF with embedded text for best results.

My Excel file has multiple sheets — will they all be converted?

Yes. MarkItDown converts all sheets and presents them sequentially in the Markdown output, labelled by sheet name.

Can I use this for large strata reports?

Yes, up to 20 MB. For very large documents the conversion may take a few seconds.

Is there an API I can call directly?

Yes — see the Technical Documentation for API endpoint details.
