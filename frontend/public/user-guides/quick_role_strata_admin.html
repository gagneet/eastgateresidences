Strata Admin Quick Guide

For organisation administrators who oversee portfolio navigation, users, settings, reporting, and building-level operational controls. Chairperson duties remain an EC appointment, not a separate login role.

You can do
  • Open portfolio, user, report, and organisation-settings areas where enabled
  • Use the building selector for assigned buildings
  • Review finance, compliance, maintenance, workflow, document, and insurance oversight menus
  • Use generated API docs and Postman artifacts when testing integration flows
You cannot
  • Bypass tenant isolation or access buildings outside your assigned scope
  • Perform Super Admin-only platform configuration unless explicitly granted

Top tasks (checklist)

  • Confirm the selected building before taking action
  • Review portfolio and reporting pages for managed buildings
  • Manage users and role permissions where your account has the required flags
  • Use finance/compliance/maintenance oversight menus to triage operational exceptions

My Property View — Personal Finance Dashboard

If your strata-admin account is also linked to an owned unit, you can access your personal Owner Dashboard via Overview → My Property View in the sidebar. This is the /dashboard/regular page — separate from the building-wide Management Dashboard.

  • "Next Estimated Payment" — shows the amount due for your next instalment only, not the total remaining for the year. This correctly accounts for any advance payments you have made.
  • Advance payments are reflected automatically — the dashboard uses the instalment algorithm:
    net_credit = total_paid − opening_arrears
    periods_funded = floor(net_credit / period_levy)
    next_payment = (periods_funded + 1) × period_levy − net_credit
  • Admin Fund / Sinking Fund health — displayed as 0% when no real data is available (no misleading placeholder values).
  • "Back to Management View" — returns you to the building-wide Management Dashboard.
Owner-linked example: When the account has an owned unit, "Next Estimated Payment" shows the next instalment amount after advance payments, not the full remaining annual balance.

Key screens (where to click)

  • Dashboard → Loads the Management Dashboard (Building Intelligence Hub) showing building KPIs, arrears, collection rate, and finance health
  • Overview → My Property View → Switches to your personal Owner Dashboard at /dashboard/regular for your unit; "Back to Management View" returns you to the Management Dashboard
  • Documents → Access levels
  • Finance → Reports / Financial Intelligence
  • Meetings → AGM preparation
  • Management → Tenant & Guest Approvals → Approve/reject incoming registrations
  • Management → User Management → Approve owner registrations; amber ⚠ icon flags owner name mismatches against the strata roll

Owner Name Verification

When an owner registers or is approved, the system automatically checks their name against the strata roll. If the name does not closely match (60 % token-overlap algorithm), an amber ⚠ triangle appears in User Management and a notification is sent.

  • Tooltip: hover the ⚠ to see "Owner name mismatch. Strata roll: <Primary> / <Secondary>"
  • Action: click Request Info to ask the owner for identity documents; verify against Certificate of Title; archive if unverified
  • Toggle: controlled by owner_name_verification feature toggle (Governance category)

Advanced Financial Enhancements

  • Debt Recovery Board — 4-tier arrears dashboard (Monitor / Contacted / DCA Eligible / DCA Referred). Path: Dashboard → Debt Recovery Board.
  • Section 83 Notices — Generate and download a formal ACT demand letter PDF for any arrears unit.
  • DCA Referral — Refer units with >$1,500 arrears (14+ days post-notice) to a Debt Collection Agency. System generates a DCA reference number automatically.
  • Payment Plans — Create structured instalment arrangements for owners unable to pay in full.
  • Special Levies — Create one-off charges for all owners, automatically split by Unit of Entitlement.
  • Bank Reconciliation — Record and verify monthly admin/sinking fund bank statements. Current balances (15 Mar 2026): Admin Fund $9,187.44 | Sinking Fund $193,337.03 | Total $202,524.47. Admin YTD spending: ~$37,250 of $309,882 budgeted (12.1%). Over-budget categories: CCTV System and Electrical Repairs.
  • Record Expenses & Income — Log building expenses against budget categories and record non-levy income.
  • Financial Health Score — View 0–100 composite score across 7 components (Arrears %, Cashflow Buffer, Surplus Ratio, etc.).
  • Levy Benefit Fairness Index (LBFI) — Gini-style metric (0–100) showing how equitably levies are distributed. Your building: 80.8. Includes subsidy map, flow matrix, and scenario comparison. Path: Dashboard → Intelligence → Levy Fairness.
  • Capital Works Planner — Dedicated planning page at Dashboard → Intelligence → Capital Planner. 3 tabs: Sinking Fund Plan (2021–2035), Capital Event Milestones, 10-Year Replacement Schedule. Strata Admin can Edit Plan on all 3 tabs where the required feature and permission flags are enabled. Current risk: HIGH (2029 repaints, $413k). Recommended levy increase: 16.1% from 2027.
  • True Cost of Ownership — Per-unit breakdown of all costs charged to each lot for the financial year.
  • Tax Summary PDF — Generate a tax summary for any unit and any financial year.

Permission Slugs (RBAC System)

As of Session 63, the platform uses a granular RBAC + ABAC permission system. Your Strata Admin role may grant the following permission slugs depending on building assignment and permission flags:

Permission slug What it allows
financial.view View all building financials
financial.approve_invoice Approve pending invoices and expenditure
financial.export Export financial reports and statements
committee.vote Vote on committee motions (inherited from EC Member)
committee.finalize_minutes Finalise and publish meeting minutes
workorder.approve Approve contractor work orders
documents.upload / documents.delete Manage document library
building.view View building configuration (not edit)
user.view View all user records in your building

Chairperson duties are represented through EC membership/position data. Strata Admin permissions are scoped to assigned building(s) and explicit flags.
