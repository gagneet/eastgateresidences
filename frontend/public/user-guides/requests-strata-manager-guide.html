Requests & Applications — Strata Manager Guide

Use Dashboard → Requests as the catalogue entry point and My Requests to inspect request lists. The available catalogue refreshes when you switch buildings.

Verified Manager Capabilities

  • Review and manage enabled request workflows for the active building.
  • Use the dedicated Maintenance page for maintenance intake and the Work Orders workspace for operational work.
  • Search/filter by category without exposing search text to analytics.

Restrictions

Do not use the catalogue to infer disabled building capabilities. Feature toggles and workflow permissions are enforced by the backend policy before catalogue submissions and by the existing domain guards for operational review actions.
