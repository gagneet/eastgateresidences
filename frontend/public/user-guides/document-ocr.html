Document OCR Workspace

Added 2026-07-27. The Document OCR Workspace reads text and structured fields out of a scanned or photographed document — AGM minutes, a rates notice, an insurance certificate, a contract, maintenance evidence, a bank statement, or any other general document — so you don't have to retype it. It is separate from, and broader than, the OCR built into Invoice upload: invoices have their own dedicated OCR step because they need very specific fields (ABN, GST, line items); this workspace is for everything else your building handles as paperwork.

Who can access this? Strata Admins, Strata Managers, and Super Admins. The page is only visible when the Document OCR feature toggle is enabled for your building.

Getting there

Dashboard → Document OCR. Choose a file, pick a document type (or leave it as "general document"), and optionally choose a specific OCR provider — most buildings should leave this on Auto, which uses whichever provider your building is configured for and falls back to a safe default automatically if that provider is unavailable.

What happens after you upload

Status What it means
Processing Your file has been received and is being read. The page checks back every couple of seconds automatically — you don't need to refresh.
Completed Extraction finished. You'll see the extracted text and any structured fields the provider found, with a confidence score.
Needs Review Extraction finished, but confidence was low enough that a human should check the result before relying on it — a common outcome for handwritten notes or poor-quality scans.
Failed The document could not be read (for example, an unsupported file, or the file was empty). You can try again with a clearer scan or a different file.
Large files run in the background. Extraction never blocks or ties up your browser request — you can navigate away and come back to the same job later from the job list.

Publishing to the document library

Once a job reaches Completed or Needs Review, click Publish to Documents to save the extracted text into your building's document library under the document type you chose — the same library used by Document Upload elsewhere in the platform, with the same permission rules for who can see it afterward.

Provider availability

Which OCR providers are available depends on how your building is configured. A basic provider is always available as a safe fallback. More advanced providers may be configured per building by your Super Admin — if the one your building normally uses is temporarily unavailable, the workspace automatically falls back rather than failing your upload.

Test / demo data

Only Super Admins can mark an OCR job as test/demo data. Test jobs and any documents published from them are excluded from your building's ordinary job list and document library views, and can be cleaned up without affecting real records.

Building isolation

Every OCR job, result, and published document is strictly scoped to your building. Managers with access to multiple buildings will only see jobs for the building they are currently logged into.
