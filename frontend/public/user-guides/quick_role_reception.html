Admin Staff Quick Guide

For admin staff handling resident requests, communications, and day-to-day building operations.

You can do
  • Review and respond to maintenance and support requests
  • Message owners and tenants in community chat
  • View meeting schedules and notices
  • Access service provider schedules
You cannot
  • Change system settings or feature toggles
  • Manage user roles or permissions
  • Access financial administration tools

Top tasks (checklist)

  • Monitor new requests and assign them to the right workflow
  • Follow up on overdue maintenance items
  • Communicate updates to owners and tenants via chat

Key screens (where to click)

  • Requests → All request types (Maintenance, Work Orders, Pet Requests, etc.)
  • Chat → Community / Private messages
  • Meetings → View schedules and notices
  • Schedule → Service provider calendar
