Document Uploads — Accepted Types & Safety

Your building's platform automatically checks every file you upload to make sure it is safe and of the expected type. This guide explains what is accepted, what is blocked, and what to do if your upload is rejected.

How File Safety Works

When you upload a file, the platform reads the file's actual content — not just its name or extension — to determine what kind of file it really is. This protects your community from accidentally sharing harmful files.

Why does this matter? A file named budget-2026.pdf could actually contain a computer program in disguise. The platform detects the real content and blocks dangerous files even when they have innocent-looking names.

This check happens automatically on every upload — you do not need to do anything differently. Safe files pass instantly. Unsafe files are rejected with a clear error message.

Accepted File Types

Documents & Office Files

.pdf .docx .doc .xlsx .xls .pptx .ppt .odt .ods .rtf .txt .csv

Images

.jpg / .jpeg .png .gif .webp .bmp .tiff .heic

When uploading to the general documents area, all of the above types are accepted. For maintenance photos, only image formats are accepted.

Blocked File Types

The following file types are always blocked, regardless of their extension. If you attempt to upload one, you will see the message: "This file type is not permitted for upload."

Category Examples Why Blocked
Windows programs .exe, .msi, .dll, .cab Executable programs — can harm devices that download them
Linux / Mac programs ELF binaries, .app, .dmg Same reason
Mobile apps .apk, .ipa, .dex Mobile application packages — not appropriate for document sharing
Shell / batch scripts .sh, .bash, .bat, .cmd, .ps1 Command scripts that can execute actions on a computer
Programming scripts .py, .php, .rb, .pl, .vbs Code files — not valid resident documents
Web scripts .js, .ts Can execute in browsers — security risk if served back to users
Java packages .jar, .class Executable Java code
Note: The extension on the file's name does not matter — the platform checks the actual file content. A program renamed to minutes.pdf is still detected and blocked.

File Size Limits

Upload Area Maximum Size
General documents (PDF, Word, Excel, etc.) 25 MB
Maintenance photos 10 MB
Financial CSV imports 10 MB
Financial PDF reports (admin) 50 MB
Document Converter 20 MB

If your file exceeds the limit, you will see: "File too large. Maximum allowed size is X MB."

For large PDFs (body corporate budgets, minutes books), consider splitting the document using a free PDF tool before uploading, or compress the PDF using "Save as reduced size" in Adobe Acrobat or macOS Preview.

If Your File Is Rejected

Error: "This file type is not permitted for upload"

1
Check the file extension. If it is one of the blocked types listed above, the platform cannot accept it.
2
If the file is a legitimate document (e.g. a PDF that is being misidentified), try re-saving or re-exporting it from the original application (Word, Adobe, etc.).
3
If you believe there is an error, contact your strata manager or an administrator and describe the file you are trying to upload.

Error: "File content does not match the expected type"

This means the file's content does not match what is expected for that upload area. For example, uploading an Excel file to the "maintenance photo" area, where only images are accepted.

1
Make sure you are uploading to the correct area. Photos go in the maintenance request photo section; financial reports go in the finance documents area.
2
If you are uploading a PDF that is being misidentified, try re-saving it as PDF from your original application. Some PDF-like files are actually other formats with a .pdf extension.

Error: "File too large"

See the size limits table above and compress or split your document.

Maintenance Photos

When attaching photos to a maintenance request, only image files are accepted: JPEG, PNG, GIF, WebP, BMP, TIFF, and HEIC (iPhone photos).

  • Maximum size: 10 MB per photo
  • PDFs, Word documents, and spreadsheets are not accepted as maintenance photos
  • Screenshots saved from your phone or computer are fine (usually PNG or JPEG)
  • iPhone photos in HEIC format are accepted — you do not need to convert them

CSV / Financial Imports (Strata Managers & Admins)

When importing financial data via CSV (levy schedules, owner details, budget categories), the platform accepts CSV, TSV, and plain text files up to 10 MB.

  • Export from Excel as "CSV (Comma delimited)" or "CSV UTF-8"
  • Do not upload the original .xlsx file — export to CSV first
  • Files with unusual characters (accented names) are handled automatically

FAQ

Can I upload a ZIP file?

ZIP files and other archive formats (.zip, .7z, .rar) are not in the standard accepted list for general documents. If you need to share multiple files, upload them individually. Your strata manager or administrator can contact support if bulk upload is needed.

My PDF was created by scanning physical documents — will it work?

Yes. Scanned PDFs (image-only PDFs) are still accepted as PDF files. Note that the Document Converter feature will detect these as "scanned PDFs" and indicate that text extraction was not possible — but they will upload to the documents section normally.

Why does the platform check my file's content, not just the extension?

File extensions can be changed easily — anyone can rename a program to report.pdf. The platform reads the actual file content to determine its true type. This protects all residents and the building's data from malicious files regardless of what they are named.

I'm an owner — can I upload confidential documents?

Yes. Documents can be marked as private (visible only to managers and EC members) or as owner-only. Talk to your strata manager about the appropriate access level for sensitive documents such as legal correspondence or insurance claims.
