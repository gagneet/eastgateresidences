Postman Quick Start

  1. Import frontend/public/tech-docs/postman/strataos_demo_collection.json or download the browser copy above.
  2. Import frontend/public/tech-docs/postman/strataos_demo_environment.json.
  3. Set base_url, demo_email, and demo_password.
  4. Run 00 Auth and Demo Setup / POST /api/auth/login to populate jwt_token.
  5. Run GET /api/buildings/me and switch to building_id=demo before testing building-scoped endpoints.

Auth and Tenant Context

  • Most endpoints require Authorization: Bearer <jwt_token>.
  • The JWT building claim is the normal tenant context. X-Building-ID is documented in Postman but disabled by default because it is only valid for super-admin context switching.
  • Every tenant-scoped request must resolve to a building. The demo environment intentionally uses demo.
