Management Hierarchy API

Router: backend/routers/management_hierarchy.py
Prefix: /management-hierarchy
Full base path: /api/management-hierarchy
Toggle: management_hierarchy_enabled

All endpoints require an authenticated, approved user (get_approved_user dependency). Access is further controlled by require_management_hierarchy_access() which resolves an access scope (platform → agency → management_entity → scheme → building) and enforces read/write gates per scope. See Access Scopes for the full scope table.

UUIDs are identifiers, not authorisation. Knowing a UUID does not grant access to any endpoint. Explicit scheme/entity/agency membership is always verified before returning data.

Endpoint Summary

MethodPathDescriptionMin role
POST /management-hierarchy/schemes/{scheme_id}/ensure Idempotent create placeholder hierarchy strata_admin or super_admin
GET /management-hierarchy/schemes/{scheme_id} Get active primary assignment + entity for a scheme Scheme read access

GET /management-hierarchy/schemes/{scheme_id}/appointments List active appointments for a scheme Scheme read access

POST /management-hierarchy/schemes/{scheme_id}/ensure

Idempotently ensures a scheme has an active primary management assignment. If one already exists, it is returned unchanged. If none exists, the appropriate core.management_entities and core.scheme_management_assignments rows are created.

Auth: strata_admin or super_admin. Also requires explicit scheme write access.

Request body

FieldTypeRequiredNotes
modestringYesagency_managed | self_managed | independent_manager | unknown
entity_name_hintstringNoMax 200 chars. Used as entity name when creating a new entity.
source_agency_idUUID stringConditionalRequired when mode=agency_managed. Must reference an existing core.agencies row.
building_idstringNoHuman-readable building identifier (scheme_number). Informational only.

Response 200

{
  "scheme_id": "uuid",
  "created": true,            // false if assignment already existed
  "entity": { ... },         // management entity fields (filtered by scope)
  "assignment": { ... },     // scheme_management_assignments row
  "warnings": []             // non-fatal issues encountered during ensure
}

Error responses

StatusCondition
400scheme_id or source_agency_id is not a valid UUID
403Caller is not strata_admin or super_admin, or lacks scheme write access
422Invalid mode value, or mode=agency_managed with missing source_agency_id
500Database error during entity/assignment creation

GET /management-hierarchy/schemes/{scheme_id}

Returns the active primary management assignment and its linked management entity for a scheme. Entity fields are filtered according to the caller's access scope.

Auth: Any authenticated user with scheme read access (EC member, assigned manager, or admin).

    "end_date": null,
    "status": "active",

GET /management-hierarchy/entities/{management_entity_id}

Returns management entity details. The entity must be linked to the caller's scheme, or the caller must have entity/agency membership.

Auth: Entity membership or scheme assignment.

Sensitive fields (abn, email, phone, legal_name) are returned only to callers with scope platform | agency | management_entity. EC members and scheme-scoped callers receive a subset without these fields.

  "email": "admin@stratasolutions.com.au",
  "phone": "+61 2 1234 5678",
  "status": "active",
  "is_system_generated": false,

  "is_independent": false,

  "created_at": "2026-06-09T00:00:00+00:00",
  "updated_at": "2026-06-09T00:00:00+00:00",

GET /management-hierarchy/entities/{management_entity_id}/buildings

Returns the list of scheme_number values for schemes currently assigned to this management entity (via active scheme_management_assignments rows).

Auth: Entity read access (same rules as GET /entities/{id}).

Response 200

{
  "management_entity_id": "uuid",
  "building_ids": ["13195", "16244", "UP-DEMO-001"],
  "count": 3
}

Error responses

StatusCondition
400management_entity_id is not a valid UUID
403Caller lacks entity read access

GET /management-hierarchy/managers/{user_id}/buildings

Returns the list of scheme_number values for buildings where the specified user has an active manager appointment (core.scheme_manager_appointments WHERE status = 'active'). Archived schemes are excluded. is_test_data = TRUE rows are filtered.

Auth: Callers may query their own user_id. strata_admin and super_admin may query any user_id. Other roles receive 403.

Response 200

{
  "user_id": "uuid",
  "building_ids": ["13195", "UP-DEMO-001"],
  "count": 2
}

Error responses

StatusCondition
400user_id is not a valid UUID
403Caller is not the target user and is not strata_admin/super_admin
500Database error

POST /management-hierarchy/schemes/{scheme_id}/appointments

Creates a manager appointment record in core.scheme_manager_appointments. EC-internal and volunteer appointment types require approved_by_ec = true before they take full effect.

Auth: strata_admin or super_admin. Also requires explicit scheme write access.

Request body

FieldTypeRequiredNotes
user_idUUID stringYesMust reference a valid core.users row
management_entity_idUUID stringYesMust reference a valid core.management_entities row
appointment_typestringYesOne of the 6 valid appointment_type values (see below)
role_titlestringYesMax 100 chars. e.g. "Strata Manager", "Building Manager"
start_datedate stringNoISO-8601. Defaults to CURRENT_DATE.
approved_by_ecbooleanNoDefault false. EC-internal and volunteer types require true.
approval_referencestringNoMax 200 chars. Meeting minute reference or motion number.

Valid appointment_type values

ValueRequires EC approval
agency_strata_managerNo
independent_strata_managerNo
ec_internal_strata_managerYes
owner_volunteer_managerYes
building_managerNo
caretakerNo

Response 200

Returns the created core.scheme_manager_appointments row as a dict.

{
  "appointment_id": "uuid",
  "scheme_id": "uuid",
  "user_id": "uuid",
  "management_entity_id": "uuid",
  "appointment_type": "agency_strata_manager",
  "role_title": "Strata Manager",
  "status": "active",
  "approved_by_ec": false,
  "start_date": "2026-06-09",
  "end_date": null,
  "approval_reference": null,
  "appointed_by": "uuid"
}

Error responses

StatusCondition
400Any UUID parameter is not a valid UUID
403Caller is not strata_admin/super_admin or lacks scheme write access
409Appointment conflicts with existing active appointment (duplicate constraint)
422Invalid appointment_type value

GET /management-hierarchy/schemes/{scheme_id}/appointments

Lists active manager appointments for a scheme. Only rows with status = 'active' and is_test_data = FALSE are returned. Results ordered by created_at DESC.

Auth: Scheme read access (EC member, assigned manager, or admin).

Field Filtering Rules

Sensitive entity fields are filtered by filter_entity_fields() in backend/services/management_hierarchy_service.py.

Scopeabnemailphonelegal_nametenant_idsource_agency_id
platformYesYesYesYesYesYes
agencyYesYesYesYesYesYes
management_entityYesYesYesYesYesYes
schemeNoNoNoNoNoNo
buildingNoNoNoNoNoNo

The full_access flag is True when access_ctx["scope"] in {"platform", "agency", "management_entity"}. When full_access = False, the filter function removes the sensitive keys before returning the dict.

Common Error Codes

HTTP StatusCause
400UUID parameter fails parse (not a valid UUID format)
401No valid JWT / session token provided
403Authenticated but access scope check failed; or role gate (strata_admin/super_admin) failed
404Requested entity/assignment/scheme not found in Postgres
409Duplicate appointment — unique constraint violation on (scheme_id, user_id, appointment_type)
422Pydantic validation error — invalid mode or appointment_type value
500Unhandled database error — check backend logs
