Council Rates — Per-Building Configuration

Council rates (water access charges, land tax allocations, and related council levies) are calculated using building-specific parameters stored in the council_rate_settings collection. Each building maintains its own Annual Unimproved Value (AUV) and total block entitlement — never inheriting another building's values.

Collection: council_rate_settings

Field Type Description
building_id string Building partition key (e.g. "16244")
financial_year string e.g. "2025-26"
block_auv float Annual Unimproved Value for the whole block (ACT Valuation Services figure)
total_block_entitlement int Sum of all unit entitlements (default 10,000)
is_configured bool true = authoritative figure; false = estimated/pending confirmation
updated_at datetime Last update timestamp
note string? Optional free-text note (e.g. source of the AUV figure)

Unique index: { building_id: 1, financial_year: 1 }. Each building has at most one settings document per financial year.

AUV Resolution Logic — _get_block_auv(settings)

The router function _get_block_auv(settings: dict) → (float, bool) resolves the block AUV in this order:

  1. If settings["block_auv"] is set and non-zero → use it. is_estimated = not settings.get("is_configured", False)
  2. Otherwise → fall back to _DEFAULT_BLOCK_AUV (the module constant). is_estimated = False (default is defined, not a guess)
The return value is (auv: float, is_estimated: bool). Reports display "(estimated)" next to the AUV when is_estimated=True.

Per-Building Settings Lookup — _get_council_settings()

The async function queries by both financial_year and building_id:

async def _get_council_settings(financial_year: str, building_id: str) -> dict:
    coll = db["council_rate_settings"]
    doc = await coll.find_one({
        "financial_year": financial_year,
        "building_id": building_id,
    })
    return doc or {}
Multi-tenant guarantee: Every query includes building_id. Sierra (16244) querying council_rate_settings will never return East Gate's (13195) record, even if both buildings share the same financial year.

PDF Report — Assumptions Section

When the annual financial report is generated (_generate_full_report_impl in services/report_service.py), the council rate settings for the current building are fetched and embedded in the report's assumptions block:

Assumption field Source Fallback
Block AUV council_rate_settings.block_auv _DEFAULT_BLOCK_AUV
Total entitlement council_rate_settings.total_block_entitlement _TOTAL_BLOCK_ENTITLEMENT = 10,000
AUV string in PDF f"${float(block_auv):,.0f}" "not configured" when block_auv is None/0

Seeding / Configuring a New Building

Run the migration or insert directly:

# Via admin API (requires super_admin token):
POST /api/council-rates/settings
{
    "building_id": "16244",
    "financial_year": "2025-26",
    "block_auv": 4708728.0,
    "total_block_entitlement": 10000,
    "is_configured": true,
    "note": "ACT Valuation Services notice dated 2025-07-01"
}
