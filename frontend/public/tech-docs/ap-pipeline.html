AP Automation Pipeline — Technical Reference

End-to-end accounts payable pipeline: OCR invoice ingestion, ABN validation, duplicate detection, invoice lifecycle state machine, recurring bill templates, and strata-jurisdiction approval gates.

AP Approval Queue

Method Path Auth Description
GET /api/ap/invoices Manager List invoices by status query param. Paginated (page, page_size).
GET /api/ap/invoices/{id} Manager Full invoice detail including transitions history.
POST /api/ap/invoices/{id}/submit Manager draft → submitted. Validates mandatory fields.
POST /api/ap/invoices/{id}/validate Manager submitted → validated. Re-runs duplicate check (exclude_id to skip self).
POST /api/ap/invoices/{id}/approve Manager validated → approved. NSW s.102 and QLD BCCM gates applied.
POST /api/ap/invoices/{id}/reject Manager Any state → rejected (terminal).
POST /api/ap/invoices/{id}/schedule Manager approved → scheduled. Requires outbound_payment_initiation_enabled toggle.

Invoice Lifecycle State Machine

Defined in backend/domain/invoice_lifecycle.py.

draft → submitted → validated → approved → scheduled → paid → reconciled
                  ↘ rejected (terminal)
                  ↘ on_hold ↔ submitted/validated/approved
validated → pending_resolution → approved/rejected
approved → disputed ↔ on_hold/reconciled
scheduled → failed → scheduled/rejected

Duplicate Detection

Three layers, checked in order (backend/domain/duplicate_detection.py):

  1. Layer 1 — Exact: DB unique match on (tenant_id, vendor_abn, invoice_number).
  2. Layer 2 — Near-dup: Same vendor_abn + total_cents + issue_date ±3 days; Levenshtein ≤2 on invoice_number. Bounded .to_list(20).
  3. Layer 3 — Content hash: SHA-256 of normalised OCR text.

exclude_id parameter skips the current document on re-validation — prevents a draft from flagging itself as a duplicate.

ABN Validation

Implemented in backend/integrations/abn_validator.py.

  • Local weighted checksum (ATO mod-89 algorithm) runs first — no network needed.
  • Cache lookup in abn_validation_cache (90-day TTL).
  • Live lookup via ATO ABR JSON service if ABR_API_GUID env var is set.
  • Offline graceful degradation: returns abn_status="Offline", treats ABN as valid.
  • 47% withholding flag: not is_valid AND supply_ex_gst > $75.

Jurisdictional Approval Gates

Applied during validated → approved transition:

  • NSW (SSMA s.102): Rejects if invoice would push budget line >10% over cap. Requires lot_count, budget_line_current_cents, budget_line_cap_cents in the request body.
  • QLD (BCCM): Rejects if invoice total exceeds $200 × lot_count. Pass lot_count in request body.
  • ACT / other: No gate — always allowed.

Phase 5 note: These inline if jurisdiction == branches will be refactored into a JurisdictionalRuleEngine. Do not add further inline branches; extend the rule engine instead.

Recurring Bill Templates

Defined in backend/domain/recurring_bills.py. Run nightly via instantiate_recurring_bills().

Type Amount logic Use case
fixed_monthly Static amount_cents Management fees, cleaning, CCTV
variable_cadence 3-period trailing median of reconciled invoices Utilities
annual_with_instalments amount_cents / num_instalments per month Insurance premiums
one_off Static amount_cents One-time repairs, claims

Idempotency key: sha256(template_id + ":" + due_date.isoformat()) — re-running never creates duplicate drafts.

OCR Pipeline

MockOCR (backend/integrations/mocks/mock_ocr.py) is used in development. Replace with a production OCR integration (e.g. Mindee, Claude Vision) by implementing the same extract_invoice(raw_bytes, content_type) interface. Fields with confidence <0.70 are flagged in low_confidence_fields.

Permissions

can_submit_supplier_invoice is a field on the Permission model (backend/models/user.py). Enabled by default for: super_admin, building_admin, strata_manager, ec_member, service_provider.
