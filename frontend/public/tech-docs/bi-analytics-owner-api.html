BI Analytics — Owner & Investor Endpoints

Investment-grade analytics for individual owners and lots. Prefix: /api/bi and /api/intelligence/investor.

Auth & Scoping

Owner endpoints enforce per-lot access control:

  • Owner — can only access data when owner_id matches the caller token and the requested building_id/ lot_number is present in the token or user_units compatibility records.
  • super_admin, strata_admin, strata_manager, ec_member — full access to any owner/lot.

The owner_id path parameter is matched against all known auth identifiers: id, _id, and user_id. Lot-specific endpoints require building_id and lot_number query parameters.

Investment Analytics

GET /bi/owner/{owner_id}/total-cost-of-ownership

Cost of ownership breakdown for one requested lot. Requires building_id, lot_number, and optional years query parameters.

Response: array entries with financial_year, levies, water, council_rates, insurance_share, maintenance_share, total_cost, and source.

GET /bi/owner/{owner_id}/yield-estimate

Estimated rental yield for owned lots based on suburb market data and building health context.

Query ParamTypeDescription
lot_numberstringRequired lot scope.

Response: PG rows include quarterly rental income, strata costs, net income, gross/net yield percentages, vacancy weeks, and source; Mongo fallback returns the investor summary service payload.

GET /bi/owner/{owner_id}/investment-risk

Building-level risk factors from the owner's perspective: sinking fund adequacy, deferred maintenance, arrears concentration, special levy risk.

Response: object with sinking_fund_shortfall, shortfall_years, own_lot_in_arrears, critical_assets_count, risk_score, and source.

GET /bi/owner/{owner_id}/building-health-context

Building health summary presented in owner-friendly language (no internal admin KPIs). Suitable for displaying on the Owner Dashboard.

Response: owner-safe building health trend entries with date, overall score, component scores, health label, and source.

GET /bi/owner/{owner_id}/capex-schedule

Upcoming capital works schedule that will affect the owner's levies. Sourced from capital_replacement_schedule and sinking_fund_plan.

Response: owner-safe capex entries currently include year, planned amount, and forecast flag; manager callers may receive the full capex-vs-plan payload.

Levy History

GET /bi/owner/{owner_id}/levy-history

Payment history for one owner lot across the requested year window.

Query ParamTypeDescription
yearsintNumber of years to return (default 5, max 10)
lot_numberstringFilter to specific lot

Response: array entries with financial_year, levy charge/payment totals, outstanding values, and source.

Arrears Status

GET /bi/owner/{owner_id}/arrears-status

Current arrears status for one requested owner lot. Reflects the same data as the BI arrears snapshot or Mongo levy ledger fallback.

Response: an object with lot_number, outstanding totals, arrears state, and source.

Investor Intelligence (investor_intelligence.py)

Prefix: /api/intelligence/investor. Higher-fidelity investment analysis for sophisticated owners and super admins. Role: super_admin, strata_admin, strata_manager, ec_member get full access; owner gets own-unit-only access.

GET /intelligence/investor/summary/{unit_number}

Comprehensive investment summary for a specific unit/lot.

Response (InvestorUnitSummary):

{
  "unit_number": "TH087",
  "owner_name": "...",
  "building_health_score": 82,
  "levy_trajectory": { "current_annual_cents": 340870, "cagr_5yr_pct": 3.2 },
  "risk_adjusted_yield_pct": 4.1,
  "capital_risk_score": 35,
  "sinking_fund_adequacy_pct": 78,
  "recommended_action": "hold | review | exit",
  "source": "postgres_bi" | "mongo"
}

GET /intelligence/investor/building-health-report

Full building health report as a PDF StreamingResponse. Covers financial health, asset condition, compliance status, and 5-year levy trajectory.

Role: super_admin, strata_admin, strata_manager, ec_member only (owners do not get PDF).

GET /api/intelligence/investor/building-health-report
Accept: application/pdf
→ StreamingResponse (PDF)

GET /intelligence/investor/levy-trajectory

Levy trend data for charting: historical actuals and 5-year CPI projection.

Response (LevyTrajectoryResult): array of {year, admin_levy_cents, sinking_levy_cents, total_cents, is_projection}.

GET /intelligence/investor/risk-adjusted-yield/{unit_number}

Risk-adjusted gross yield for a specific unit, factoring in sinking fund risk, deferred maintenance risk, and building health score as discounts to the raw market yield.

Response (RiskAdjustedYieldResult):

{
  "unit_number": "TH087",
  "gross_yield_pct": 4.8,
  "risk_discount_pct": 0.7,
  "risk_adjusted_yield_pct": 4.1,
  "risk_factors": [
    { "factor": "sinking_fund_adequacy", "impact_pct": -0.3, "severity": "low" },
    { "factor": "deferred_maintenance",  "impact_pct": -0.4, "severity": "medium" }
  ]
}

Role access for investor/summary and risk-adjusted-yield

Owner callers are validated: the unit_number must appear in their user_units records. Mismatched unit number returns 403, not 404 (to avoid enumeration).
