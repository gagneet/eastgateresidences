BI Analytics — Portfolio, Agency & Platform Endpoints

These endpoints aggregate across multiple buildings. All use prefix /api/bi.

Manager Portfolio Endpoints

Toggle: bi_portfolio_analytics_enabled.
Role: super_admin, strata_admin; strata_manager (own portfolio — manager_id must match caller's user ID, unless super_admin/strata_admin).

GET /bi/manager/{strata_manager_id}/summary

Portfolio summary across the manager's assigned buildings.

Response: manager-scoped summary object from get_agency_summary, wrapped with route metadata. Field names are service-owned and should be checked in backend/services/bi_service.py before client binding.

GET /bi/manager/{strata_manager_id}/buildings

List of assigned buildings with per-building KPI snapshot. Used to populate the manager portfolio grid.

Response: array of assigned building identifiers; KPI cards are loaded through the per-building BI endpoints.

GET /bi/manager/{strata_manager_id}/arrears-hotspots

Top arrears lots across all assigned buildings. Maximum 30 results ordered by arrears descending.

Response: array of {building_id, lot_number, owner_name, arrears_cents, months_overdue}.

GET /bi/manager/{strata_manager_id}/compliance-overdue

Compliance items past due or expiring within 30 days across the manager's portfolio.

Response: array of {building_id, domain, expiry_date, days_overdue}.

GET /bi/manager/{strata_manager_id}/health-ranking

Buildings ranked by financial health score descending. Surfaces buildings needing attention.

GET /bi/manager/{strata_manager_id}/workload

Request volume and SLA breach count per building, for workload balancing.

Response: array of {building_id, open_requests, sla_breached, avg_days_to_resolve}.

GET /bi/manager/{strata_manager_id}/upcoming-actions

Upcoming AGMs, compliance deadlines, levy schedule dates, and contract renewals across the portfolio. Returns items within the next 90 days, ordered by due_date ascending.

Agency Endpoints

Toggle: bi_analytics_agency_enabled (depends on bi_analytics_platform_enabled).
Role: super_admin, strata_admin. The agency_id is the strata company's tenant_id in core.tenants.

GET /bi/agency/{agency_id}/summary

Top-level summary for an agency's entire portfolio.

Response: agency summary object from get_agency_summary; avoid assuming cent-suffixed API fields because the service converts cents to display values in several paths.

GET /bi/agency/{agency_id}/buildings

All buildings under the agency with KPI snapshot. Equivalent to manager/buildings but scoped to the full company.

GET /bi/agency/{agency_id}/financial-summary

Aggregate financial KPIs across all agency buildings.

Response: per-building financial summary rows using the same keys as /bi/building/{building_id}/financial-summary.

GET /bi/agency/{agency_id}/arrears-hotspots

Top arrears lots across all agency buildings (max 50).

GET /bi/agency/{agency_id}/compliance-overdue

Compliance overdue items across all agency buildings.

GET /bi/agency/{agency_id}/health-ranking

Buildings ranked by health score; used for portfolio triage.

GET /bi/agency/{agency_id}/maintenance-risk

Buildings ranked by deferred maintenance risk score.

GET /bi/agency/{agency_id}/budget-vs-actual

Budget variance per building for the current financial year.

Platform Endpoints (Super Admin)

Toggle: bi_analytics_platform_enabled.
Role: super_admin only. Returns cross-agency aggregates for all buildings on the platform.

GET /bi/platform/summary

Platform-wide aggregate: total buildings, lots, agencies, arrears, compliance health.

GET /bi/platform/agencies

All strata companies with their building count, lot count, and aggregate KPIs.

GET /bi/platform/buildings

All buildings across the platform with KPI snapshot. Used for admin triage dashboard.

GET /bi/platform/feature-adoption

Feature toggle activation rates across buildings. Shows which buildings have each feature enabled. Used for rollout tracking.

GET /bi/platform/data-freshness

Per-building data freshness report: last sync timestamps for Mongo→PG ETL, levy data, compliance data.

GET /bi/platform/etl-health

ETL pipeline health across all buildings: success/failure counts, row counts, staleness flags.

Management Entity Endpoints

Toggle: management_hierarchy_enabled.
Role: super_admin, strata_admin. The management_entity_id refers to core.management_entities.id.

These endpoints mirror the agency tier but scope to a single management entity (a team or office within a strata company) rather than the full company.

GET /bi/management-entity/{management_entity_id}/summary

GET /bi/management-entity/{management_entity_id}/buildings

GET /bi/management-entity/{management_entity_id}/financial-summary

GET /bi/management-entity/{management_entity_id}/health-ranking

GET /bi/management-entity/{management_entity_id}/compliance-overdue
