Capital Funding & Special Levy Workspace

Planned/Pilot: The first implementation must be calculator, owner-impact report, governance evidence and levy-notice preview only. Live issuance and ledger posting require separate protected toggles.

Purpose

This workspace is intended for major capital events: remediation, cladding, structural defects, emergency repairs, major insurance premium increases, lift replacement, solar or EV infrastructure, and other costs that may require special levies or strata finance.

Target Data Flow

staff project inputs
  -> funding scenario calculator
  -> lot entitlement and ownership snapshot
  -> owner impact report
  -> AGM/SGM/GM motion and owner voting/elections
  -> legal and governance approval gate
  -> frozen calculation manifest
  -> levy notice PDF preview batch
  -> dual approval
  -> demo issuance / shadow ledger
  -> controlled production issuance and posting

Feature Toggles

  • capital_funding_workspace - staff calculator and scenario workspace.
  • capital_funding_owner_elections - owner vote/election pages.
  • capital_funding_notice_preview - one-click PDF preview batches.
  • capital_funding_notice_issuance - actual email/portal/postal notice delivery.
  • capital_funding_ledger_posting - canonical ledger posting after approval.
  • hybrid_funding_structures - legally reviewed hybrid/self-funding structures only.

Integration Points

  • Finance: reads lots, entitlements, funds, levy schedules and owner balances.
  • Levy Fairness: supplies class and benefit-group evidence for mixed-use scenarios.
  • Governance: links funding scenarios to AGM/SGM/GM motions, votes and decision records.
  • Documents: stores quotes, contracts, lender term sheets, legal reviews and meeting evidence.
  • Hardship: offers confidential owner help requests and payment-plan workflow links.

Backend API (shipped)

POST /finance/capital-funding/preview — preview-only, guarded by capital_funding_workspace plus an explicit role check (super_admin/strata_admin/strata_manager/admin_staff). Wraps the pure calculator in backend/domain/capital_funding.py and the jurisdictional rules engine's typed accessors. Returns per-lot allocation/interest/fee impacts, a reconciliation total, the jurisdiction's rule summary, and explicit warnings (unverified notice period, hybrid request, unsupported allocation basis). Performs zero writes — no database session is opened. The staff workspace page (CapitalFundingPage.tsx) is not yet wired to this endpoint — it still uses its own local-only calculator; see tasks/GAP-FIN-034-capital-funding-special-levy-workspace.md's "Deliverable C" for that remaining work.

Controls

The preview batch must validate allocation totals, one notice per current lot, jurisdictional notice periods, owner delivery addresses, joint-owner handling, calculation-manifest hash and zero live ledger/email mutation during preview.

See tasks/GAP-FIN-034-capital-funding-special-levy-workspace.md and docs/features/levy-loan-automated-levy-notices-analysis.md for the implementation plan.
