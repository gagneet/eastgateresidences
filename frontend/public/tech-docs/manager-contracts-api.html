Manager Contracts API

Router: backend/routers/manager_contracts.py
Prefix: /manager-contracts
Full base path: /api/manager-contracts

Tracks strata manager agreements for legislative compliance. All endpoints are building-scoped via get_current_building() — the authenticated user's building context is injected automatically and cannot be spoofed via the request body.

Storage: MongoDB. Manager contracts are stored in the manager_contracts MongoDB collection (scoped by building_id). This is distinct from the management hierarchy feature which uses Postgres exclusively. The contract_id path parameter is a MongoDB ObjectId.

Endpoint Summary

MethodPathDescriptionMin role
GET /manager-contracts/expiring List contracts expiring within N days EC or manager
POST /manager-contracts Create contract record EC or manager
GET /manager-contracts List contracts (paginated) EC or manager
GET /manager-contracts/{contract_id} Get single contract EC or manager
PUT /manager-contracts/{contract_id} Update contract (terminate, add document, etc.) EC or manager
Route ordering. GET /expiring is registered before GET /{contract_id} to avoid the path /expiring being interpreted as a contract ID. This ordering is maintained in the router source.

Legislation

This router enforces statutory constraints on strata manager agreements:

JurisdictionActSectionRule
ACT Unit Titles (Management) Act 2011 s.60 Strata manager agreements must not exceed 3 years (36 months)
ACT Unit Titles (Management) Act 2011 s.61 Contract must be disclosed at a general meeting before taking effect
NSW Strata Schemes Management Act 2015 s.49 Managing agency agreements must not exceed 3 years; no auto-renewal clauses
ACT Property & Stock Agents Bundled Acts 2004 — Strata manager licence required (ACT Revenue Office)
NSW NSW Fair Trading — Real estate licence with strata management endorsement required

The maximum duration (36 months) is looked up per jurisdiction via JurisdictionService.get_rule_value(building_id, "manager_contract_max_years"). Auto-renewal clauses are unconditionally rejected (HTTP 400) regardless of jurisdiction.

GET /manager-contracts/expiring

Returns contracts where contract_end_date falls between today and today + days_ahead, and status is not terminated. Results are sorted ascending by contract_end_date.

Use this endpoint to initiate renewal or tender processes. ACT UTMA 2011 s.60 requires re-tender or a fresh OC resolution before expiry.

POST /manager-contracts

Creates a strata manager contract record. Enforces duration and auto-renewal constraints before writing to MongoDB. Creates an audit log entry via create_audit_log().

Returns HTTP 201 on success.

The building_id is always taken from the authenticated user's building context (get_current_building()) — the value in the request body is overwritten to prevent BOLA/IDOR spoofing.

GET /manager-contracts/{contract_id}

Returns a single contract by MongoDB ObjectId. Enforces building isolation: the document is fetched with {"_id": oid, "building_id": building_id} so a manager cannot retrieve contracts from other buildings even if they know the ObjectId.

Path parameter

contract_id — MongoDB ObjectId string (24-character hex). Returns 400 if not a valid ObjectId format.

Response 200

Single contract object including all computed fields.

Error responses

StatusCondition
400contract_id is not a valid MongoDB ObjectId
403Caller role not in allowed set
404Contract not found (or belongs to a different building)

PUT /manager-contracts/{contract_id}

Partial update — all fields are optional; at least one must be supplied (400 if empty). Re-validates contract_duration_months and auto_renewal if provided. Creates an audit log entry.

To terminate a contract, set status = "terminated" and supply terminated_at (ISO-8601 datetime) and optionally termination_reason.

Computed Fields

The _enrich_contract() function appends computed fields to every document before it is returned. These are not stored in MongoDB.

FieldLogic
days_until_expiry (contract_end_date - today).days. Negative = expired. Null if date unparseable.
status terminated if terminated_at is set;
expired if days_until_expiry < 0;
active otherwise.
max_duration_months 36 for ACT and NSW (both UTMA 2011 s.60 and SSMA 2015 s.49).
is_compliant True when all of:
contract_duration_months ≤ 36
auto_renewal = false
licence_expiry_date not in the past (or not set)
compliance_issues Array of human-readable issue strings. Possible values:
  • Duration exceeds max months (UTMA/SSMA citation)
  • Auto-renewal clause present (prohibited)
  • Licence expired N days ago
  • Contract not yet disclosed at a general meeting (UTMA s.61)

Roles

All endpoints use _require_manager() which checks effective_role(user) in {"super_admin", "strata_manager", "strata_admin", "ec_member", "admin_staff"}.

RoleAccess
super_adminFull access across all buildings
strata_adminFull access within their managed buildings
strata_managerFull access within assigned buildings
ec_memberFull access within own building
admin_staffFull access within own building

Note: chairman is not a top-level role (removed in migration 0025 / commit 67fbc4a5). EC chairmen have role ec_member with ec_position = "CHAIRMAN". The ec_member role in the allowed set covers them correctly.

Storage

Documents are stored in the manager_contracts MongoDB collection. All queries include building_id from the auth context — the TenantScopedDatabase wrapper auto-injects this.

Contract IDs are MongoDB ObjectId values converted to strings (str(doc.pop("_id"))). When providing a contract_id in path params, it must be a 24-character hex string. Invalid ObjectId format returns HTTP 400.

Unlike the management hierarchy and SM organisations features, there is no Postgres equivalent for manager contracts at this time. Contracts remain MongoDB-only.
