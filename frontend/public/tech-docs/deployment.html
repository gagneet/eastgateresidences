Deployment & Configuration

Complete reference for deploying and configuring the East Gate Residences platform in production.

Environment Variables

Never commit .env files to git. Use backend/.env.example as a template. The .gitignore excludes .env.

Backend Deployment

Install Dependencies

cd backend
pip install -r requirements.txt

Run Development Server

cd backend
uvicorn server:app --reload --host 0.0.0.0 --port 8003

systemd Service (Production)

# Service file: /etc/systemd/system/eastgate-backend.service
[Unit]
Description=Eastgate Backend
After=network.target mongod.service

[Service]
User=eastgate
WorkingDirectory=/home/eastgate/strata-management/backend
ExecStart=/usr/bin/uvicorn server:app --host 127.0.0.1 --port 8003 --workers 2
Restart=always
RestartSec=5
EnvironmentFile=/home/eastgate/strata-management/backend/.env

[Install]
WantedBy=multi-user.target
# Control commands
sudo systemctl start eastgate-backend
sudo systemctl stop eastgate-backend
sudo systemctl restart eastgate-backend
sudo systemctl status eastgate-backend

# View logs (last 100 lines, follow)
sudo journalctl -u eastgate-backend -n 100 -f

Cache Cleanup (after code changes)

# Clear Python bytecode cache
find backend/ -type d -name "__pycache__" -exec rm -rf {} + 2>/dev/null
find backend/ -name "*.pyc" -delete 2>/dev/null

# Then restart
sudo systemctl restart eastgate-backend

Nginx Configuration (production — with Cloudflare)

Nginx listens on port 80 only. Cloudflare terminates TLS. The config lives in deploy/nginx/eastgate.conf and is installed to /etc/nginx/sites-available/eastgate by deploy/install.sh. 
upstream eastgate_backend  { server 127.0.0.1:8003; keepalive 32; }
upstream eastgate_frontend { server 127.0.0.1:3020; keepalive 32; }

server {
    listen 80;
    server_name eastgateresidences.com.au www.eastgateresidences.com.au;

    # NextAuth internal routes → Next.js (must come before /api block)
    location ~ ^/api/auth/(callback|csrf|session|signin|signout|providers|error|verify-request)(/|$) {
        proxy_pass http://eastgate_frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto "https";
        proxy_set_header CF-Connecting-IP $http_cf_connecting_ip;
        proxy_set_header CF-IPCountry $http_cf_ipcountry;
        proxy_buffer_size 256k; proxy_buffers 8 512k; proxy_busy_buffers_size 512k;
    }

    # FastAPI backend: /api/auth/login, /api/auth/me, and all other /api/*
    location /api {
        proxy_pass http://eastgate_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto "https";
        # CRITICAL: forward Cloudflare real-IP headers so FastAPI logs correct client IP
        proxy_set_header CF-Connecting-IP $http_cf_connecting_ip;
        proxy_set_header CF-IPCountry $http_cf_ipcountry;
        proxy_read_timeout 300;
    }

    # Everything else → Next.js frontend
    location / {
        proxy_pass http://eastgate_frontend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto "https";
        proxy_set_header CF-Connecting-IP $http_cf_connecting_ip;
        proxy_set_header CF-IPCountry $http_cf_ipcountry;
        proxy_buffer_size 256k; proxy_buffers 8 512k; proxy_busy_buffers_size 512k;
    }
}

Common MongoDB Queries (Mongo Shell)

// Count users by role
db.users.aggregate([{$group:{_id:"$role",count:{$sum:1}}}])

// Find users pending approval
db.users.find({is_approved:false, status:{$ne:"archived"}})

// Check a unit's 2026 levy
db.unit_levy_ledger.findOne({unit_number:"TH017", year:"2026"})

// List all feature toggles
db.feature_toggles.find({},{key:1,is_enabled:1,_id:0})

// Update a feature toggle
db.feature_toggles.updateOne({key:"finance"},{$set:{is_enabled:false}})

Email Configuration

Migadu SMTP (Primary)

  • Host: smtp.migadu.com
  • Port 465: SMTP_SSL (implicit TLS) ← recommended
  • Port 587: SMTP + STARTTLS
  • Username: full email address
  • From: noreply@eastgateresidences.com.au
SMTP_HOST=smtp.migadu.com
SMTP_PORT=465
SMTP_USER=admin@eastgateresidences.com.au
SMTP_PASSWORD=xxxx
SMTP_SECURITY=ssl

{ "to": "test@example.com" }

# Or from server directly
cd backend
python3 test_smtp_connection.py

Troubleshoot SMTP

  • Error 421: Username/sender mismatch → ensure SMTP_USER matches SENDER_EMAIL domain
  • Error 553: Sender doesn't exist in Migadu → create the mailbox
  • Error 535: Wrong password → update in email-settings UI

Cron Jobs (systemd Timers)

All scheduled tasks run as systemd one-shot services triggered by timers. Service files live in deploy/systemd/ and are installed to /etc/systemd/system/ by deploy/install.sh.

Timer Schedule Script Purpose
eastgate-finance-recompute Daily 02:00 UTC cron/cron_finance_recompute.py Recompute levy totals, arrears, KPIs
eastgate-maintenance-intelligence Daily 17:00 UTC cron/cron_maintenance_intelligence.py Asset health scores, risk predictions
eastgate-archive-stale Daily (random delay) scripts/archive/archive_stale_registrations.py Archive expired registration tokens
eastgate-auto-approve Every 5 min cron/cron_admin_auto_approve.py Auto-approve guests/tenants N min after owner-approved
eastgate-payment-reminders Daily 22:00 UTC (08:00 AEST) cron/cron_payment_reminders.py Levy, council rates, water bill reminders
eastgate-notification-cleanup Weekly Sunday cron/cron_notification_cleanup.py Purge old notifications
eastgate-news-scraper Every 6 hours cron/cron_news_scraper.py RSS + Serper news articles
eastgate-property-scraper Twice daily cron/cron_property_scraper.py Property listings (East Gate only) 
# Check timer status
systemctl list-timers --all | grep eastgate

# View cron job logs
tail -f /var/log/eastgate/finance-recompute.log
tail -f /var/log/eastgate/auto-approve.log
journalctl -u eastgate-auto-approve -n 50

# Manually trigger a cron job
sudo systemctl start eastgate-finance-recompute.service
sudo systemctl start eastgate-auto-approve.service

Troubleshooting

Symptom Likely Cause Fix
502 Bad Gateway Backend service stopped sudo systemctl restart eastgate-backend
503 on API calls Backend not listening on port 8003 Check journalctl -u eastgate-backend -n 50
Login returns 500 MongoDB not running or wrong MONGO_URL Check systemctl status mongod
Frontend shows old build Browser cache Hard refresh (Ctrl+Shift+R) or clear cache
JWT expired errors 24h token expiry Normal — user must log in again. Check JWT_SECRET matches
Email not sending SMTP config incorrect Test with POST /api/email-settings/test
Feature toggle not working Toggle not seeded Run python3 seeds/feature_toggles.py
Import fails 422 Model validation error Check request body matches Pydantic model. Check unit_number is a string
PDF download empty ReportLab error Check backend logs for reportlab exceptions
403 on owner route Permission flag missing Check user permissions in DB; check check_permission() call
Login audit shows 127.0.0.1 GeoIP lib absent + old code path Fixed 2026-03-09 — update to latest code & restart backend. Verify CF-Connecting-IP is forwarded by nginx.
Cron timer not firing Timer not enabled after deploy sudo systemctl enable --now eastgate-auto-approve.timer (repeat for each timer)
