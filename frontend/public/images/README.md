# Images Directory

This directory should contain the East Gate Residences images used in the application.

## Required Images

Place the following images in this directory:

1. **east-gate-hero.webp**
    - Hero image for the About page
    - Recommended size: 1920x1080px
    - Format: WebP (optimized for web)
    - Alt text: "East Gate Residences"

2. **east-gate-exterior.jpg**
    - Exterior/facade image for the About page
    - Recommended size: 1200x800px
    - Format: JPEG
    - Alt text: "East Gate Residences facade"

## Image Guidelines

- Use high-quality images that represent the building professionally
- Optimize images for web (compress without losing quality)
- Use WebP format where possible for better performance
- Maintain aspect ratios appropriate for the display contexts

## Placeholder Images

Until real images are provided, the application will show broken image placeholders. You can use placeholder services
temporarily:

```jsx
// Temporary placeholder example:
<img src="https://via.placeholder.com/1920x1080/2F4F4F/FFFFFF?text=East+Gate+Residences" />
```
